 Search Algorithms (Іздеу алгоритмдері)

📌 Жобаның мақсаты
Бұл жобада линейлік (Linear Search) және бинарлық (Binary Search) іздеу алгоритмдері қарастырылған. Олардың жұмыс істеу принципі мен айырмашылығы көрсетілген.

---

 🔍 Linear Search (Линейлік іздеу)
- Массивтегі әр элементті бір-бірлеп тексереді
- Сұрыптау қажет емес
- Қарапайым, бірақ баяу

📊 Күрделілігі: O(n)

---

 ⚡ Binary Search (Бинарлық іздеу)
- Тек сұрыпталған массивте жұмыс істейді
- Массивті екіге бөліп іздейді
- Өте жылдам алгоритм

📊 Күрделілігі: O(log n)

---

 📊 Салыстыру
- Linear Search → баяу, бірақ кез келген массивте жұмыс істейді
- Binary Search → жылдам, бірақ тек sorted массив керек

---

 🎯 Қорытынды
Бинарлық іздеу тиімдірек, бірақ ол тек сұрыпталған массивте қолданылады. Линейлік іздеу қарапайым және әмбебап болып табылады.
